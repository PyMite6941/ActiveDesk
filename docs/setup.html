ActiveDesk ⁃ Setup

Install on every device

Install Tailscale and ActiveDesk on each device you want to reach, all signed into the same Tailscale account.

Step 1 — Tailscale

Install Tailscale on every device and sign in to the same account:

  • Windows / macOS: download from tailscale.com/download, or winget install Tailscale.Tailscale on Windows and brew install --cask tailscale on macOS.
  • Raspberry Pi / Debian / Ubuntu: curl -fsSL https://tailscale.com/install.sh | sh, then sudo tailscale up.
  • iPhone: install the Tailscale app from the App Store and sign in.

Once signed in, each device gets a 100.x.y.z tailnet address. That’s what ActiveDesk uses to reach it‭—‭nothing is exposed to your LAN or the internet.

Step 2 — Java 17+

ActiveDesk needs Java 17 or newer.

  • Windows: winget install EclipseAdoptium.Temurin.21.JRE
  • macOS: brew install --cask temurin
  • Raspberry Pi / Debian / Ubuntu: sudo apt install openjdk-17-jre

Step 3 — ActiveDesk

Download activedesk.jar

Or build it yourself: ./build.sh (Linux/macOS/Git Bash) or build.cmd (Windows), which produces dist/activedesk.jar.

Run it: java -jar activedesk.jar. The first start prints an 8-digit web PIN. Write it down‭—‭you’ll enter it on your phone.

Step 4 — Open from your phone

  1. On the iPhone, open the Tailscale app and make sure it’s connected.
  2. Open Safari and go to http://<device-name>:47801 or http://100.x.y.z:47801‭—‭for example http://100.65.117.75:47801.
  3. Enter the 8-digit PIN shown when ActiveDesk started.
  4. Tap the share button ↗ then “Add to Home Screen.” It now works like an app.

For HTTPS (needed if you want the phone to keep its own screen on while viewing), run tailscale serve --bg 47801 on the device and open https://<device>.<tailnet>.ts.net.

One-line install (Linux / Pi / macOS)
$ curl -fsSL https://pymite6941.github.io/ActiveDesk/install.sh | sh
One-line install (Windows PowerShell)
> irm https://pymite6941.github.io/ActiveDesk/install.ps1 | iex
One-time setup: battery charge limits and Windows power modes need admin once. The installer offers to run activedesk setup, which walks you through Tailscale, the screen check, device name, PIN and autostart.
Raspberry Pi: use the X11 desktop session, not Wayland‭—‭sudo raspi-config → Advanced → Wayland → X11. Screen capture does not work under Wayland.
