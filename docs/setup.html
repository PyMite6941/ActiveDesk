ActiveDesk ⁃ Setup

Install, set up, run, and uninstall

Install ActiveDesk on every device you want to reach, all signed into the same Tailscale account.

1. Install

Choose one way to install. Each installs the activedesk command and starts the setup wizard.

One-line install (Linux / Raspberry Pi / macOS)
$ curl -fsSL https://pymite6941.github.io/ActiveDesk/install.sh | sh
One-line install (Windows PowerShell)
> irm https://pymite6941.github.io/ActiveDesk/install.ps1 | iex

What the installer does:

  1. Checks for Java and Tailscale. Offers to install them if missing.
  2. Downloads activedesk.jar from the latest release.
  3. Checks its SHA-256 against SHA256SUMS.txt. It stops if they don’t match.
  4. Adds the activedesk command and starts the setup wizard.

Optional settings (set them before running the installer):

  • ACTIVEDESK_VERSION: install a specific release, e.g. v1.0.0.
  • ACTIVEDESK_JAR: use a jar you already have instead of downloading.
  • ACTIVEDESK_YES=1: accept every default, no questions.

Or install manually — the release bundles already include Java, so nothing else is needed except Tailscale:

  • Windows: download ActiveDesk-windows-x64.zip from Releases v1.0.0, extract it, run activedesk.exe.
  • macOS: download ActiveDesk-macos-arm64.tar.gz, extract it, run ./activedesk.
  • Linux: download ActiveDesk-linux-x64.tar.gz, extract it, run ./activedesk.
  • Raspberry Pi (64-bit Pi OS): download ActiveDesk-linux-arm64.tar.gz, extract it, run ./activedesk (use X11, not Wayland).
  • Any OS with Java 17+: download the portable activedesk.jar and run java -jar activedesk.jar.
Tailscale is required first. Install Tailscale on every device and sign in to the same account before installing ActiveDesk. Each device then gets a 100.x.y.z address that ActiveDesk uses to reach it — nothing is exposed to your LAN or the internet.

2. Set up (first run)

The first time you run ActiveDesk it prints an 8-digit web PIN. You enter this PIN on your phone or another computer to unlock the web app.

$ activedesk

Then run the guided setup wizard (takes about a minute, press Enter to accept defaults):

$ activedesk setup

The wizard walks you through:

  1. Tailscale — confirms it is running and signed into the same account as your other devices.
  2. Screen — detects whether this device has a screen; on headless devices it offers to enable Tailscale SSH.
  3. Device name — the name shown on your other devices.
  4. Web PIN — write it down; you enter it on your phone to unlock the app.
  5. Keep screen on — session (while controlled), always (kiosk), or off.
  6. Power + battery — optional one-time admin setup for battery charge limits and power modes.
  7. Start automatically — sets up autostart so ActiveDesk runs when the device starts.

Run activedesk setup --yes to accept every default without asking (useful for scripting).

After setup, the wizard tells you the address to open on your phone, e.g. http://100.x.y.z:47801/.

3. Run

Open the app:

$ activedesk
  1. It starts ActiveDesk if it isn’t running yet.
  2. It opens the app in your browser at http://127.0.0.1:47801/.
  3. Enter your PIN.

Already running? It just opens the browser. On a device with no screen (like a headless Pi), it prints the address instead.

To start ActiveDesk without opening a browser (for servers and scripts):

$ activedesk run

From your phone or another computer, open http://<tailscale-ip>:47801/ over Tailscale and enter the PIN.

To start automatically at login, run activedesk install-service (Startup entry on Windows, LaunchAgent on macOS, XDG autostart on Linux).

4. Uninstall

ActiveDesk does not scatter files across your system. To remove it completely:

  1. Stop the node: close the terminal, or taskkill /F /IM java.exe (Windows) / pkill -f activedesk.jar (Linux/macOS).
  2. Remove autostart (if you set it up): disable the Startup entry / LaunchAgent / XDG autostart that activedesk install-service created.
  3. Delete the app folder:
    • Windows: delete %LOCALAPPDATA%\\ActiveDesk
    • macOS/Linux: delete ~/.local/share/activedesk and ~/.local/bin/activedesk
  4. Delete the data folder (optional): removes your config, PIN, audit log, and chat history.
    • Windows: %APPDATA%\\ActiveDesk
    • macOS/Linux: ~/.activedesk
  5. Uninstall Tailscale (optional): remove the Tailscale app if you no longer need it.
Uninstalling ActiveDesk does not remove Tailscale or Java — those are separate installations.

CLI commands

CommandWhat it does
activedeskStart ActiveDesk if needed and open the app in your browser.
activedesk runStart ActiveDesk only, no browser (used by autostart).
activedesk setupGuided first-time setup wizard (PIN, Tailscale check, autostart, power).
activedesk setup --yesAccept all setup defaults without asking.
activedesk install-serviceStart ActiveDesk automatically at login/boot.
activedesk chat [room]Terminal chat (or nc <device> 47800).
activedesk send <device> <file>Send a file to another device.
activedesk who / activedesk tasksConnected devices / scheduled tasks.
activedesk run-task <id>Run a scheduled task (and its dependencies) now.
activedesk lockEnd every web / remote-control session immediately.
activedesk awake [off|session|always]Keep the screen on (session = while controlled, always = kiosk).
activedesk pinSet a new web PIN.
activedesk statusTailscale + config summary.
activedesk selftestRun the built-in end-to-end test (what CI runs).
activedesk power installOne-time admin/root setup for power mode, brightness, charge limits.
activedesk power uninstallRemove the power/battery privileged setup.

Phone setup (iPhone, iPad, Android)

  1. Install Tailscale on the phone and sign in to the same account as your computers.
  2. Open Safari (iPhone/iPad) or Chrome (Android) and go to http://<device>:47801 over Tailscale.
  3. Enter the 8-digit PIN shown when ActiveDesk started on the computer.
  4. Tap the share/menu button ↗ then “Add to Home Screen.” It now appears as a real app icon.
Keep Tailscale running in the background on your phone so you can reach your computers from anywhere — mobile data or Wi-Fi.
Raspberry Pi: use the X11 desktop session, not Wayland (sudo raspi-config → Advanced → Wayland → X11). Screen capture does not work under Wayland.
