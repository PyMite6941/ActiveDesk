Questions

Short answers, plain words.

Is it free?

Yes. ActiveDesk itself is free and open source. Tailscale Personal is free for individual use. The docs and installers are hosted on GitHub Pages. Java (OpenJDK) is free. Nothing requires a paid plan.

Which operating systems work?

Anything that runs Java 17+: Windows, macOS, Linux, and Raspberry Pi (64-bit Pi OS). Remote screen capture needs a display‭—‭use X11 on the Pi, not Wayland. A device without a screen still works: it offers Tailscale SSH instead.

Does it work over my phone’s mobile data?

Yes‭—‭as long as the phone has Tailscale on and connected. The phone reaches each device’s Tailscale address directly through the WireGuard tunnel, so mobile data or Wi-Fi both work.

Is anything exposed to the internet?

No. ActiveDesk listens only on loopback (127.0.0.1) and the device’s Tailscale IP‭—‭never on your LAN or the internet. Only devices signed into your Tailscale account can connect, plus any logins or tags you allow. Wrong PIN guesses are rate-limited.

Can someone else on my Wi-Fi reach it?

No. Nothing listens on LAN interfaces, so other devices on your Wi-Fi can’t connect.

How is remote control secured?

Nothing is drawn on the controlled screen, so it is never interrupted. Instead, every remote-control session is announced in chat, and every login, control session, file transfer, wake and power change is written to an audit log. Sessions are bound to the client IP and expire after 30 minutes idle or 12 hours.

Can I type at the Windows lock screen?

No app can‭—‭Windows forbids it by design. Use Sign-in screen (RDP), which downloads an .rdp file pointing at the Tailscale IP. Needs Windows Pro with Remote Desktop enabled.

Can I charge-limit any laptop?

Not every one. On Windows this works for ASUS and Dell (with Dell Command | Configure). Lenovo, HP, Surface and similar have no software charge-limit API. Linux works on many laptops whose kernel exposes charge-threshold files (ThinkPad, ASUS, Dell, Framework and others). macOS and desktops have no software charge limit.

What if a device is asleep?

Use Wake in the Devices tab. It sends a wake-on-LAN packet, relayed through any awake ActiveDesk device on the same LAN‭—‭so an always-on Raspberry Pi can wake your Windows laptop.

Where are bugs reported?

Use GitHub’s “Report a vulnerability” button (Security tab) for security issues. For everything else, open an issue on GitHub.

Limits: remote control runs with your own user rights, so OS lock screens and UAC prompts can’t be automated. Tailscale is part of the trust base‭—‭whoever controls your Tailscale account decides which devices count as yours.
