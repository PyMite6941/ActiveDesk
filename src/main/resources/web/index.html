This device has no screen

Use a terminal instead, with Tailscale SSH (free, no passwords or keys to copy):

  1. Once, on this device: sudo tailscale set --ssh
  2. From a computer with Tailscale: paste the command above into a terminal.
  3. From a phone: any free SSH app (e.g. Termius) → host , user , no password.

Windows can't be a Tailscale SSH server. Turn on the free built-in OpenSSH Server (Settings → System → Optional features) and use the same command with ssh.
